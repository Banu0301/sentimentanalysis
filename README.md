
# 💬 AI Sentiment Analyzer

This project is a simple yet powerful **Sentiment Analysis Web App** built with 🤗 **Hugging Face Transformers** and **Gradio**. It uses a pre-trained DistilBERT model fine-tuned on the SST-2 dataset to classify input sentences as **Positive** or **Negative**, with emoji feedback and confidence scores.

---

## 🧠 What It Does

- Detects sentiment of each input sentence
- Supports batch input (one sentence per line)
- Adds emojis 😊 / 😞 based on sentiment
- Displays prediction confidence scores
